# Rediscovery and translation ledger

Purpose: absorb established science before claiming novelty. This is a working literature map drawn from the research conversations and the archived notes, with a few additional primary-source links checked in the November 2026 integration round. It is not an exhaustive systematic review. Some entries identify a mathematical special case; others only name an adjacent idea. No cross-domain equivalence is promoted from resemblance alone.

## Promotion rule

For each suggested identity, freeze the source objects, domain of admissible auxiliary choices, construction/translation map, equality criterion and defeat condition. Test both directions if claiming equivalence. If a mature method reproduces the behavior for equal or lower cost, record absorption. If only a structural resemblance is available, keep the status as analogy or NO TRANSLATION EARNED. Cross-domain rediscovery is a way to generate hypotheses, not proof of originality, and model-assisted rediscoveries are not independent of prior scientific training.
