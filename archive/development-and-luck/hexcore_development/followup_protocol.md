# DEV-02: attack the generative result with learned expert selection

Follow-up specified while DEV-01 full run was in progress; not part of its original protocol. The edge and balanced generators are known to the experimenter and already included in DEV-01's fixed mixture. Test a conventional selector that uses exactly the anonymous successful shapes to learn which of those existing generators to use. No test feedback. This is a strong in-family control, not a universal solver.

For each training law and seed, calculate the probability of each observed ordered tree under three existing experts: uniform Catalan, edge splits, balanced splits. Smooth each expert's tree distribution with 5% uniform probability (to avoid zeros) and select the expert of maximum summed log likelihood; use its smoothed distribution in the test. Charge node visits for all three likelihood evaluations and one score update per observation; train costs are those of DEV-01. Test on identical held-out suites, common seeds, and the same 2500 proposals. Also report a strict equal-lifetime-work version using the DEV-01 pooled grammar lifetime budget minus the selector training and fitting proxy. All target families supplied in the expert library. A superior result for this baseline would defeat any assertion that a new developmental mechanism was necessary. Report all suites, paired descriptive comparisons, fit selection counts, actual search time, and work. No claim of originality or out-of-family generalization.
