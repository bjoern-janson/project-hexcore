# Hexcore developmental inheritance: DEV-01 / DEV-02

Executed exploratory tests, not an emergent chemistry or a demonstration of recursive self-improvement. Read `protocol.md` (written before the initial full run; a two-seed smoke check used the same seeds later included in the full run) and `followup_protocol.md` (specified during the first full run). Run `python development.py` then `python followup.py` with Python 3.10+ and NumPy. The JSON records all 24 seeds, learned model counts, anonymous training shapes, target truth tables, search work proxies, elapsed search times, paired descriptive intervals and negative outcomes. The supplied input-label permutations are shared across arms. `run.log` and `followup.log` preserve execution summaries. The smoke run is not a separate source of evidence.

## Main finding

Under matched training/test shape laws, a pooled, size-independent split grammar learned from exact binary success signals transfers better than literal subtree reuse, size-indexed split counts, a neutral fitted grammar and fresh uniform or fixed mixture search. All four pooled-vs-equal-lifetime-fixed-mixture mean differences are positive (edge 7 +16.46, edge 8 +3.92, balanced 7 +3.63, balanced 8 +3.21 distinct functions out of 64); paired descriptive intervals exclude zero. The pooled grammar's serialized counts occupy 33 bytes on average, compared with ~335 bytes for the anonymous subtree library (not total runtime memory). This is a conventional hand-specified statistical grammar, not a new cognitive primitive.

The shift destroys specialization: edge-trained pooled grammar finds 0.04 of 64 balanced eight-input targets on average, versus 60.75 for the equal-lifetime fixed mixture. Balanced-trained pooled grammar finds zero edge eight-input targets, versus 2.83 for the mixture. Neutral and general target results are also in the archive. More training improves some matched coverage but does not establish recursive developmental improvement; the two training stages are independent uniform searches, with pooled records rather than sequentially evolving the generation law.

## Stronger ordinary control

DEV-02 selects one of three provided shape generators by maximum smoothed likelihood on exactly the same anonymous training records. It selects the matched law on all 48 seed/world pairs. At equal lifetime proxy budget, matched coverage is 37.67, 6.96, 63.92, 63.96 versus pooled 38.58, 6.75, 63.92, 63.96 (edge 7/8, balanced 7/8). Descriptive intervals for all four paired differences include zero. The expert selector's measured test generation/evaluation time is lower in all four settings. It is a family-aware control, not a universal baseline, and also fails under shifts. No new developmental mechanism is needed to explain the positive result. It is ordinary transfer of structural inductive bias.

## Costs and limits

The work budget charges fully expanded NAND evaluation at a scalar-operation proxy, training and simple fitting counters. Actual bit-parallel computation differs. Full test streams are generated without feedback. The target generator, read-once constraint, leaf count, split feature categories, membership oracle and grammar family are supplied. Cost accounting does not include all actual computation and memory; held-out targets share the experimenter's generator family. The evaluator's external coverage sets do not constitute persistent agent memory. Expert selection knows the two true growth families as options. All distinct discovered hit functions in each run were independently evaluated over all input assignments. Timings are machine-specific and exploratory; confidence intervals are descriptive. No claim of emergent reasoning, physical evolution, general intelligence or improved asymptotic complexity follows. No repository changes were made in this round.

## Next gate

Test changing environments in which the useful developmental law is not among an installed family of experts. Compare generative rule discovery against standard Bayesian/grammar induction, neural/program-synthesis and library baselines. Separate the ability to retain a rule from the ability to identify when it should be replaced. Charge both lifetime acquisition and reacquisition, and hold the evaluation language fixed while the subject changes. Preserve the current result as a scope-limited positive plus an absorption control.
