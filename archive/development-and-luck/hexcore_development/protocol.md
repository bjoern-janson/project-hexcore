# DEV-01: developmental inheritance vs inherited components

Exploratory protocol written before execution. Follow-up to the failed term chemistry. This is finite program search, not abiogenesis. All candidates are ordered read-once NAND trees, each input label used once. All have n-1 expanded gates. A supplied developmental grammar is fitted, not invented by the medium.

24 paired seeds. Two training worlds: edge (split off one leaf at every node), balanced (split as evenly as possible). Generate distinct target truth tables by randomly permuting labels: 8/24 edge targets at sizes 4/5, 3/15 balanced targets. A binary membership oracle signals exact matches. Draw 500 and 1000 uniform Catalan trees respectively. Record the first successful anonymous shape per distinct function, not the labels. Also sample matched numbers of random proposals as neutral training records. No target information is supplied during test generation.

Held-out sizes 7,8, 2500 proposals per arm, fresh labels, separate seeds. Each stream is scored against 64 independently generated distinct functions in each of edge, balanced and uniform families. Matched and shifted distributions are separate. Share label RNG across arms. Primary comparisons pooled grammar vs fragment library and fixed mixture; also fresh baselines with total lifetime work budget. Training and test share supplied structural family biases; no out-of-grammar claim.

Arms: uniform Catalan; fixed equal mixture of uniform, edge and balanced; size-indexed anonymous subtree library (use matching fragment with probability .8, else recurse with uniform Catalan split); size-specific empirical split grammar (one Catalan pseudocount, unseen sizes default to Catalan); pooled grammar (learn edge/central/other split counts over nodes with >1 possible categories, add one per category, use available categories and choose uniformly within category); neutral pooled grammar fit on matched random proposals; pooled4 only fit on size 4 successes. The pooled rule is a standard supplied probabilistic grammar parameterization, not novel. Fresh lifetime uniform and mixture get all training work plus pooled fitting and test work, thus earlier access to test vocabulary.

Work proxy per proposal: (n-1)*2^n scalar gate operations + 2^n ideal full-output membership units + (2n-1) construction tokens + n label units. Charge training and fitting (node visits and prepared table entries), report model storage as deterministic JSON bytes and measured search time. Bit-parallel implementation, not actual energy or FLOPs; oracle construction, generator sampling, allocator, evaluator and bookkeeping not fully charged. External evaluator's accumulated hits are not resident capacity. Verify each distinct generated hit via independent scalar evaluation of all inputs. Report paired descriptive bootstrap intervals and all conditions, no multiplicity correction. Preserve failures. Failure to beat lifetime controls defeats acceleration in that setting; poor shift performance defeats general transfer.
