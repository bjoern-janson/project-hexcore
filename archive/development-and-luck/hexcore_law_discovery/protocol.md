# DEV-05: induce a construction law

Exploratory protocol written before the run. Unlike DEV-01–04, this is a structural-demonstration interface, not binary membership: a query at size n returns the root split of a successful anonymous read-once NAND tree. A common recursive tree constructor and general arithmetic language are supplied. No specific target formula or menu of target laws is supplied to the learner. No claim of open-ended invention.

Domain n=2..64. Clamp the integer smaller-child size to [1,floor(n/2)]; recursively apply the same law to both children, smaller first. Train on n=4,5, and three distinct sizes from 6..16. Held-out n=17..64. Measure exact root prediction, exact full ordered-tree reconstruction, and equality of NAND truth tables at n=17 across all 131072 inputs, using the same leaf labeling. No held-out feedback.

Enumerate expressions with 1,3,5,7 nodes over n, constants 1..4, operations +,-,*, floor division, remainder, min,max. Exclude division by zero anywhere in domain and magnitude >4096 at any intermediate. Deduplicate raw full-domain behaviors at minimum node count, then deduplicate clipped profiles. Choose minimum node count compatible formula, ties lexicographically. Active queries maximize Shannon entropy of candidate split predictions weighted by 2^(-node count); ties smaller size. Passive uses identical library and 32 random query schedules per world; sequential uses 6,7,8. If no candidates remain use nearest observed split, flag elimination. Conventional controls fit a fraction with denominator <=16 or nearest observed split on the exact active observations. Chain/half reference controls included.

Evaluator-only laws: thirds, quarters, two-fifths, alternating denominator 2+n%2, capped thirds, modular denominator 1+n%3, integer square root, integer log2, thirds through n=16 then halves, thirds through n=16 then quarters. Last two alias exactly with thirds under any permitted training queries. Report actual finite-language membership, not assumed expressibility. These worlds are deliberately designed, not independently sampled natural problems. Repeated active observations are not independent runs.

Record enumeration attempts, scalar evaluation upper-bound proxy, storage, fitting comparisons and entropy visits, timings, compatible profiles, all predictions, and outcomes. Charge enumeration separately; shared amortization is not free. No claim of total computation advantage. A direct-test oracle would use a different access contract. If simpler learners match, record absorption. If aliases survive, no general extrapolation guarantee. No inference about intelligence, physics, or P=NP.
