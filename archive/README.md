# Historical artifacts

Original chat-generated Python and JSON artifacts are archived under this directory when retrievable. These are exploratory snapshots, not a polished package. Some scripts use absolute /mnt/data paths, import sibling scripts, execute work at import time, or assume NumPy. Inspect before execution; use a disposable environment and adjust paths in a separate replay branch, not in historical source. No independent rerun or benchmark certification is claimed by this import.

The artifact manifest records which files could be transferred. The original artwork is excluded because rights and provenance were not established. Personal conversation material unrelated to the research is omitted. No new license is assigned without owner direction.
